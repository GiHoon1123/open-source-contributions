# Open Source Contributions

Merged open source contributions and technical notes.

This repository only contains PRs that were accepted and merged upstream. Work-in-progress notes, closed PRs, and private review logs are kept separately.

## Structure

```text
typescript/
  merged TypeScript / JavaScript contributions

kotlin/
  merged Kotlin / Kotlin contributions

java/
  merged Java / Java contributions
```

Each note records the issue, root cause, fix, tests, and review outcome for one contribution.
